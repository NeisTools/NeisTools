# 나이스 도구 모음 (NeisTools)

나이스 관련 프로그램을 한 화면에서 골라 설치하고, 새 버전이 나오면 한 번에 올리는 작은 프로그램입니다.

## 쓰는 법

1. 받은 zip 파일을 **먼저 압축 해제**합니다. (압축 프로그램 안에서 바로 실행하면 안 됩니다.)
2. 풀린 폴더에서 `NeisTools.bat` 을 두 번 누릅니다.
3. 목록에서 설치하거나 업데이트할 프로그램에 체크합니다.
4. `선택한 것 설치·업데이트` 를 누릅니다. 각 프로그램의 설치 창이 차례로 뜹니다.

상태 칸의 뜻:

| 상태 | 뜻 |
| --- | --- |
| 미설치 | 이 PC 에 없습니다. 체크하면 새로 설치합니다. |
| 새 버전 있음 | 설치된 것보다 새 버전이 있습니다. 처음부터 체크되어 있습니다. |
| 최신 | 손댈 것이 없습니다. |
| 확인 못 함 | 인터넷이 안 되거나 받는 곳에 닿지 못했습니다. |

목록은 온라인에서 읽으므로, 프로그램이 추가되면 도구 모음을 다시 받지 않아도 목록에 나타납니다.

## 개인정보와 통신

- 이 프로그램은 학생 자료를 열거나 읽지 않습니다. 각 프로그램의 설정이나 인증 정보도 읽지 않습니다.
- 인터넷 통신은 GitHub 에서 **목록, 버전 정보, 설치 파일을 받는 것**뿐입니다. 이 PC 의 정보를 보내지 않습니다.
- 받은 설치 파일은 올려 둔 것과 해시(SHA-256 또는 SHA-512)가 같을 때만 실행합니다.
- 이 PC 에서 읽는 것은 Windows 의 "설치된 앱" 목록에 있는 이름과 버전뿐입니다.

## 문제가 생기면

- **아무 창도 뜨지 않음**: zip 을 풀지 않고 실행했는지 확인합니다. `NeisTools.bat` 과 `NeisTools.ps1` 이 같은 폴더에 있어야 합니다.
- **"Windows 의 PC 보호" 창**: `추가 정보` → `실행` 을 누릅니다. 서명이 없는 프로그램이라 처음 한 번 나옵니다.
- **백신이 막음**: 백신 설정은 이 프로그램이 바꾸지 않습니다. 학교 정보 담당자에게 문의하거나, 각 프로그램의 설치 파일을 직접 받아 설치합니다.
- **확인 못 함**: 학교망에서 GitHub 가 막혀 있을 수 있습니다. 다른 망에서 다시 해 봅니다.
